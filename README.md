# Restore GLP-1 Checkout

Checkout for **Restore GLP-1**. Shoppers choose a treatment, enter contact and shipping details, apply a coupon when one is offered, pay, and reach the order confirmation page.

The repository name is `restore1monthcheckout` because this project is the checkout code for Restore GLP-1.

## Stack

- React
- Vite
- Tailwind CSS
- TypeScript
- Stripe

## Requirements

- Node.js 18 or later
- npm

## Run locally

```bash
git clone https://github.com/shiv-dev-01/restore1monthcheckout.git
cd restore1monthcheckout
npm install
npm run dev
```

The dev server opens at http://localhost:5173.
